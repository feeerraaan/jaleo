📖 Documentación de Jaleo

Tu DJ de Spotify en WhatsApp. Solo una persona necesita Spotify Premium: el resto del grupo pide canciones en el chat y el bot las reproduce.

⏸ Estado actual: la instancia pública del bot está en pausa (migración del VPS a Vercel). Esta página y el código en GitHub están abiertos como portfolio. La guía de instalación completa se está reconstruyendo aquí; mientras tanto, el README del repo es la referencia.

Cómo funciona

Grupo de WhatsApp → IA (OpenClaw) → jaleo-api (Express) → Spotify API
  1. Alguien escribe "pon Rosalía" en el grupo.
  2. La IA interpreta el mensaje en lenguaje natural.
  3. Llama al webhook de jaleo-api con la acción.
  4. La API ejecuta la acción en Spotify (play, pause, queue, volumen…).

A diferencia de Spotify Jam, nadie necesita tener la app instalada: basta con escribir en el grupo.

Auto-hospedaje (resumen)

La guía paso a paso completa está en reconstrucción. Resumen de requisitos:

  • Servidor con Node.js 20+ (VPS, Raspberry, etc.)
  • Dominio con HTTPS (p. ej. Caddy con Let's Encrypt)
  • Número de WhatsApp dedicado + cuenta de Spotify Premium
  • App en Spotify Developer (Client ID + Secret)
  • API key de un proveedor de IA

Variables de entorno (ver .env.example en el repo): PORT, BASE_URL, SPOTIFY_CLIENT_ID, SPOTIFY_CLIENT_SECRET, REDIRECT_URI.

Referencia completa en el README de GitHub.

Stack técnico

  • jaleo-api: Node.js, Express, SQLite, Axios
  • Bot: WhatsApp + agente de IA (OpenClaw)
  • Proxy: Caddy con Let's Encrypt · Procesos: PM2
  • Auth: Spotify OAuth 2.0 con auto-refresh
